MoviesWave - Movie Ticket Booking System
----------------------------------------

MoviesWave is a Python-based desktop application for booking movie tickets. It features a graphical user interface (GUI) made using Tkinter and connects to a MySQL database for managing data. The project is suitable for both administrators and regular users to browse movies and book tickets easily.

Requirements:
-------------
- Python 3.10.7
- XAMPP Server
- Web Browser (for managing the database via phpMyAdmin)
- Windows Operating System

Python Libraries Installation:
------------------------------
Easy Way:
- Open the "requirement" folder.
- Double-click the file named "requirement.bat" to install all necessary libraries.

If you prefer manual installation, run the following commands:
    pip install pillow
    pip install tkcalendar
    pip install matplotlib
    pip install scipy
    pip install numpy
    pip install mysql-connector-python
    pip install cython
    pip install imagetk

How to Set Up the Project:
--------------------------
1. Start Apache and MySQL from XAMPP.
2. Open your browser and go to: http://localhost
3. Click on "phpMyAdmin".
4. Create a new database named exactly: MoviesWaves
   (⚠️ If the database name is different, the project will not run.)
5. Import the database file provided in the project folder into phpMyAdmin.
6. Run the file named "front_logo.py". The project should now start.
